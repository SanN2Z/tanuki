# tanuki 成员培训指南

**读指南 → 把项目交给 Agent → 按交接结果使用。**

tanuki 是我们的网络环境检测与配置流程。成员了解怎么开始和日常使用，具体命令、配置与验证交给本机 Agent。

项目地址：<https://github.com/SanN2Z/tanuki>

## 第一次使用

准备好能在这台电脑执行命令的 Agent，以及管理员分配的节点或家宽配置文件。还没拿到配置，先告诉 Agent“尚未分配”。

打开 Agent，把下面整段发给它：

```text
请获取 https://github.com/SanN2Z/tanuki，读取 SKILL.md 并执行。
这是一台个人日常使用的电脑，主要使用浏览器和 Claude Code。
已有配置先检测并修复，没有配置则从零准备；优先复用管理员分配的资源。
请自动完成已授权的必要安装和可逆配置，缺信息时只问具体缺项。
保留正在使用的代理和远程连接；涉及活动线路、系统代理、TUN 或防火墙切换时，先准备方案和回退，再让我确认。
完成后给我主线路、实际出口、日常启动方式、恢复方法和后续复查入口。
```

如果用的是 Desktop、IDE、手机或远端机器，把第二行换成实际设备和应用。Agent 能读取本地配置时，直接告诉它文件位置；登录、系统密码和验证码在原应用中输入。

## Agent 会完成什么

1. 读取项目流程，确认这次要配置的设备、应用与已有资源。
2. 检测已有环境，完成必要配置，验证实际应用是否走预期出口。
3. 留下日常使用与恢复说明；需要你操作时，只给出当前缺少的一步。

GitHub 暂时无法访问时，让管理员把完整仓库 ZIP 发到本机，再让 Agent 读取其中的 `SKILL.md` 继续。普通网页聊天窗口不能直接修改电脑，需要使用有本机文件和终端权限的 Agent。

## 配好以后，平时怎么用

- 先启动交接说明中的代理客户端，使用已验证的主线路，再打开常用浏览器或 Claude 客户端。
- 保持交接时的线路和代理设置，按管理员提供的日期续费。
- 保存 Agent 留下的配置位置、实际出口、恢复方法和 `RUN.md` 路径，出问题时交给它续查。

正常使用不需要每天重新配置或扫描。换设备、换网络、升级客户端，或出现具体报错时，再让 Agent 检查受影响的部分。

### 只需要理解这三个词

| 名称 | 含义 |
|---|---|
| 节点 | 代理客户端中的一条连接配置，通常由管理员分配 |
| 出口 IP | 网站实际看到的网络来源地址，以实测结果为准 |
| TUN / 断线保护 | 负责接管流量、处理代理失效的设置，按交接说明保持 |

## 出问题，把这段发给 Agent

```text
请按 https://github.com/SanN2Z/tanuki 的流程排查。
我的设备 / 应用：……
现象、开始时间和完整报错：……
其他网页能否访问：……
上次交接或 RUN.md 的本地位置：……
请先只读定位，给出原因、修复办法和需要我做的一步。
```

额度耗尽按提示的恢复时间处理；连接超时先查网络和服务状态；明确提示账号停用时按官方通知处理。手机和远端机器需要分别检查各自的连接。

## 分发与适用范围

这份指南和 GitHub 地址可以转发给成员。节点链接、订阅、密码和本机运行记录只交给指定维护者，留在私有位置。

tanuki 用于配置与排查，实际服务使用遵守平台规则；固定出口和检测结果不保证账号不会受限。
