# 裸机启动、资源开通与进度

先完成 SKILL.md 的用途与模式确认。本文件的安装、资源开通和切换步骤用于从零配置；检测模式仅使用已有工具与进度记录，按 detection.md 执行。

## 最低条件

用户有一台自己能管理的 Windows、macOS 或 Linux 电脑，以及能读文件、执行终端命令的 agent。技能是工作说明，不是独立程序。

完全没有 agent 时，先把技能包解压到本机，再安装/登录用户选择的 agent，打开本文件所在目录。若 agent 需要联网但当前网络不可用，用户先完成校园认证，或在可联网设备下载官方安装包后离线传入。登录、验证码和系统密码由用户在原应用交互输入。

不要求预装 Git、Node、Python、Docker、Homebrew 或浏览器 MCP。已有的工具优先复用；仅在后续步骤实际需要时安装。浏览器执行工具缺失不会阻止系统和网络配置。

## 本机启动顺序

1. 识别 OS、架构、当前账号、管理员权限、可用 shell，确认命令真正运行在目标电脑。
2. 查当前接口、默认网关、DNS、校园认证状态、代理/VPN、远程管理依赖。按 platforms.md 取证，保持现有连接。
3. 选择私有 <work-dir>，记录本次目标。Windows 推荐用户目录下的 .tanuki/runs；不要放入同步盘、公共项目或技能包。
4. 已有 Python 3 时用 collect_environment.py；没有就先用原生命令。想使用批量采集器时通过 Python 官方安装渠道补齐，或用系统已有软件管理器安装；不把缺 Python 报成网络故障。
5. 新客户端：桌面环境优先当前稳定的 Clash Verge Rev；无桌面 Linux 或专用网关可用 Mihomo。下载与 OS/CPU 匹配的官方发行版，记录实际版本。保留已工作的客户端，不为了技能统一界面迁移它。
6. 部署 VPS 或通过 SSH 管理中转机时需要 SSH 客户端；新 VPS 分支才需要服务端 sing-box。Windows 缺 OpenSSH 时通过系统可选功能安装；macOS/Linux 用已有 ssh。独立配置试连不要求先开启 TUN。

Windows 运行 .ps1 使用 UTF-8 BOM 与 UTF-8 输出；命令行中用 curl.exe。macOS 与 Linux 使用系统原生 shell。不要假设 Linux 容器有 systemd。

## 资源选择

已有可用 JP 出口先复用。没有出口时只收集会改变购买条件的偏好：希望 VPS 还是住宅/ISP、每月预算、设备数/大致流量、主要接入网络。两者皆可且没有住宅要求时，可先选用户自有日本 VPS；住宅出口另走住宅分支。

| 资源 | 开通前确认 | 用户返回什么 |
|---|---|---|
| 日本 VPS | 可管理的 Linux 系统、地区、独立端口/公网地址、校园网可达性、月流量和总价、控制台救援入口 | IP/域名、SSH 用户/端口、密钥本地路径或别名、控制台确认的主机身份、系统/架构、允许部署的范围 |
| 日本住宅/ISP 代理 | JP 最终出口、协议与第一跳 TLS、账号或 IP 白名单认证、静态/粘性时长、并发/流量/有效期、UDP 支持 | 私有配置文件路径、协议/端口、认证方式、预期出口、白名单状态、设备数 |
| 自有日本家宽网关 | 网关有权管理、在线、可从外部访问；确认公网/CGNAT 与现有隧道 | 已有 VPN/代理私有配置，或可管理的 SSH/VPN 入口和授权 |
| 中转 | 仅在目标网络无法稳定直达最终出口时考虑；不能暗换最终出口 | 本人授权入口与私有配置路径，预期连接链 |
| 基础网络 | 正常校园/运营商认证、能访问必要安装源 | 认证完成或离线安装包路径 |

无需默认为 VPS 购买域名、额外家宽或第二台服务器。已有日本住宅代理也不必再租 VPS；只有第一跳、可达性或用户要求需要中转时才增加资源。

给具体商家建议时，查询其当前官方套餐和退款/试用条件，列所需规格、预计月费与流量，标明数据库地区和住宅类别仍待购买后实测。不能用历史套餐或 IP 营销词承诺体验。

## 暂停单

先准备已能完成的内容，再把确实依赖人的工作交出去。示例：

~~~text
状态：待用户 · B2
已完成：本机基线、接入方案、配置模板和所需端口。
缺少：可管理的日本 VPS。
请完成：按已选预算开通机器，保留控制台访问。
返回：IP、SSH 用户/端口、本地密钥路径或别名、主机身份来源、OS/架构。
请勿粘贴：私钥、密码、节点 URL 或订阅内容。
恢复：$tanuki 继续 <work-dir>/RUN.md，VPS 已开通，信息在 <本地文件路径>。
下一步：验证 SSH 与服务端条件，部署并在本机隔离试连。
~~~

其他人工步骤同样说明“具体动作 / 返回证据 / 续接阶段”：

- 校园门户、验证码、服务商付款：用户在原站点完成，返回完成状态。
- 家宽白名单：添加实际连接代理的来源 IP；有中转时通常是中转出口，由测量确认。返回生效状态。
- UAC、sudo、系统扩展/VPN 权限：给出当前命令或系统面板位置，用户在本机完成，随后重测。
- 无法安全切换唯一远程连接：准备配置、回退命令与现场步骤，等现场入口可用后进入 B4。
- 明确的协议/线路故障：附已验证的层与待提供的控制台记录，不让用户无依据地反复购机。
- 需要重启才能生效：列受影响应用和已保存状态；用户确认可中断后执行或由用户重启，再回到 B6。

已有授权且工具能完成的普通配置不拆成逐条确认。人工步骤未完成时，停下依赖它的动作，保留可独立完成的检查，不循环催问。

## RUN.md

agent 用普通 Markdown 维护一份进度即可，不需要额外状态服务。最少内容：

~~~text
用途：个人电脑 / 中转机 / 兼用；中转机实际承担的功能
模式：从零配置 / 检测；是否明确授权检测后修复
目标：按分配资源确定国家，未指定时 JP；最终出口类型；覆盖哪些应用/下游；应用所在设备的地区目标
设备：OS/架构、实际运行上下文、网络类型
授权：允许修改的本机/远端、是否允许当前网络切换
链路：电脑 → [中转] → 最终出口 → 目标服务
阶段：配置 B0～B6 或检测 D0～D3，各自完成/进行中/待用户/未验证
当前阻塞：具体条件、所需用户动作、恢复后第一步
资源：私有文件路径、SSH 别名；不写凭据正文
已完成证据：时间、命令/工具、配置值或实测结果、所在文件
改动：原值/备份路径、现值、恢复命令、生效状态
下一步：一个可执行动作
~~~

续接时读取记录及当前相关运行状态；资源、接口或活动配置变化了才重测受影响项。私密明细写本地配置，给用户的分享版隐藏完整 IP、凭据与私人路径。人工阻塞解除不代表部署已通过，要按原阶段的验收条件继续。
