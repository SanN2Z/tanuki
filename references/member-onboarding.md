# 培训入口与成员交接

对应成员阅读的 [Claude 使用指南](../docs/training-guide.md)。成员提供自己分配到的资源，再把仓库地址和用途交给能在目标电脑执行命令的 Agent；日常使用以 Claude Code CLI 为主。

## 获取与开始

1. 获取完整的 [tanuki 仓库](https://github.com/SanN2Z/tanuki)，读取根目录 `SKILL.md`。本地已有副本时先确认来源与工作区状态，保留用户修改，避免覆盖。
2. 有 Git 时可克隆仓库；没有 Git 时下载 [完整源码 ZIP](https://github.com/SanN2Z/tanuki/archive/refs/heads/main.zip) 并解压。用户也可以在可联网设备下载后传入。只取得 `SKILL.md` 时补齐所需 references、scripts 和 assets 后再执行相关步骤。
3. 当前任务可直接从仓库目录执行，不要求成员先手动安装 skill。用户需要后续快捷调用时，再按所用 Agent 的技能目录安装完整文件夹。
4. 确认命令运行位置是用户要配置的电脑。纯网页聊天、工具服务器或远端容器无法操作该设备时，明确需要本机执行入口，保留已准备的文件和下一步。

获取与阅读仓库不自动授权检测。只有用户同时提出检测或配置目标时，才进入 `SKILL.md` 的执行流程。

## 沿用成员已经提供的信息

指南中的标准请求已说明：个人日常电脑、Claude Code CLI 与登录浏览器、已有配置先检测并修复，没有配置从零准备。直接沿用这些选择，按当前设备事实选择相应分支；用户另行指定手机、中转机、Desktop、IDE 或远端运行时，以本次说明为准。

“已有配置”指已提供或设备上确有适用于目标应用的配置来源。可以只读核对文件、客户端和应用设置，随后说明进入检测修复或从零配置。发现已有配置但不确定属于谁、预期出口是什么时，先问这一项，不重做整套用途问答。

首次只补充会改变执行路径的信息：

- 管理员提供的节点 / 家宽配置在本机什么位置，或尚未分配。
- 实际使用哪些应用，以及它们运行在本机、WSL、容器还是 SSH 远端。
- 是否通过远程桌面、校园网或跳板维持当前管理连接。

系统版本、已安装软件、代理监听和现有配置优先只读获取，无需让成员逐项抄写。账号登录、系统密码、付款和验证码由成员在原应用完成；节点凭据从获授权的本地文件读取。

## 自动配置与人工动作

执行用户已授权的必要安装、配置与可逆修复，采用 `SKILL.md` 的 D0–D3 或 B0–B6。具体平台、资源和测试步骤沿用已有参考文件。

用户采用指南中的 CLI 配置请求时，复用已有官方客户端，缺少时按当前官方安装说明准备；核对 CLI 的有效代理、实际执行位置和认证方式，账号登录由用户在官方流程中完成。验收实际 CLI 请求，交付从项目目录启动、恢复会话和查看 `/usage` 的方法。浏览器登录路径单独确认，不能代替 CLI 验收。

活动配置、代理组、TUN、系统代理、防火墙或现有连接需要切换时，先准备候选、测试、影响和回退，按项目规则及本次授权继续。保持运行中的 Clash Verge / Mihomo，不通过重启或终止现有代理进程加载变更。唯一远程入口可能断开且缺少恢复条件时，停在待接入。

资源不足时，继续完成不依赖它的部分，在私有 `RUN.md` 中给出一个具体人工动作和续接位置。没有分配节点时，请成员向管理员取得配置文件；成员未要求采购时，不把团队接入转为自行租机。用户明确选择自购后，才按 bootstrap.md 处理资源开通。

## 交给成员的结果

按实际范围完成验收后，交付一段可以保存的使用说明：

~~~text
设备与应用：
主线路名称：
实际出口与测量时间：
日常启动与使用方法：
恢复本次改动的方法：
私有配置与 RUN.md 位置：
未完成事项及下一步：
~~~

续费日期从管理员或服务商资料登记；无此信息时保留待补充。实际应用尚未通过时，先给当前结果和具体下一步，不能用配置文件已生成替代完成。

复查时读取原 `RUN.md`，结合用户说明和近期改动，只验证受影响的路径。成员换网络、换设备、升级客户端或收到具体报错时，按相关分支继续。
