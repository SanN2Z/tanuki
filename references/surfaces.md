# 网络与识别面

先按 roles.md 区分个人电脑、中转机及应用实际运行位置。个人应用与下游转发分别取证，纯转发机不以本机语言/时区代替下游浏览器。每次检测应能回答：发现差异后，会具体改哪一项。

## 网络

| 检测面 | 取证方式 | 如何使用结果 |
|---|---|---|
| 出口国家、ASN、运营商 | 从实际路径向两家独立 IP 服务查询，记录来源与时间 | JP 是数据库结论；不一致时保留两份结果，不推断实际所在地 |
| IPv4 与 IPv6 | 访问相应地址族专用服务，结合路由与连接日志 | IPv4 成功不代表 IPv6 走同一路径；IPv6 不通不能报“无泄漏” |
| 浏览器、CLI、IDE、Desktop | 同时段比较各自出口 | 不同结果时检查代理继承和分流，不能拿一个应用替代另一个 |
| 系统代理、PAC、WPAD | 系统设置与 PAC 实际匹配 | 配有地址不代表启用，PAC 可按域名返回 DIRECT |
| HTTP(S)、ALL_PROXY、NO_PROXY | 大小写变量、进程与持久变量分别读取 | 解释优先级和绕过项；Claude Code 不支持 SOCKS，不能与 HTTP CONNECT 混同 |
| TUN、默认路由、应用排除 | 正在运行的 TUN、IPv4/IPv6 路由、进程排除 | 配置文件不是运行证明；关闭系统代理而启用 TUN 仍可能正常接管 |
| Clash/Mihomo 分流 | 运行配置、规则顺序、策略组选择、连接链 | “日本”节点名只是标签；订阅模板不等于运行配置 |
| DNS UDP/TCP 53 | 系统解析器、TUN DNS 接管、代理日志与受控查询 | 解析器地址不能证明路径；中国 DNS 可能仅用于代理域名 bootstrap |
| 浏览器与系统 DoH | 浏览器策略、系统配置、受控域名查询 | DoH 可能独立于系统 DNS；解析器地区不等于用户地区 |
| DNS 递归出口 | 有现成服务时使用随机域名测量 | 普通查询或 IP 查询不能代替；无测量条件记未验证，无需另建外部服务 |
| WebRTC/STUN | ICE host、srflx、relay 候选、协议，与 HTTP 出口对照 | 私网地址、链路本地、TUN 使用的保留地址和 mDNS 不等于公网泄漏；无候选不能证明安全 |
| QUIC/UDP/HTTP3 | 实际协议与代理 UDP 覆盖，必要时应用网络日志 | HTTP 成功不覆盖全部 UDP；证明旁路后再调整，不默认全局关闭 |
| WebSocket、登录回调 | 现有连接的目标与路由记录 | 仅测首页不足；只读检查不退出登录或新建 OAuth 授权 |
| 断线、重连、失效回退 | failover、DIRECT 回退与既有断线日志 | 不在活跃会话中主动断网；停机演练需单独安排 |
| Wi-Fi、有线、热点、VPN | 用户实际会使用的接口与路由 | 只覆盖实际支持路径，不扫描附近网络或读取 SSID 历史 |
| 网关与转发头 | 对照 HTTP CONNECT、反向网关、TLS 终止与受控回显 | Forwarded/X-Forwarded-For 是否暴露来源需请求证据；加密 CONNECT 不等于反向网关，不安装中间人证书 |
| 目标域名覆盖 | 当前官方网络文档与应用连接记录 | IP 检测网站的出口不能代替全部 Claude 目标连接 |

curl -4/-6 在 HTTP 代理下可能只约束到代理的地址族，不能据此断言代理出站地址族。使用 IPv4-only/IPv6-only 目标取证，并标明测量的连接段。

## 系统与地区

| 检测面 | 证据 | 判读与动作 |
|---|---|---|
| 时区与偏移 | OS 时区、/etc/localtime、进程 TZ、浏览器 Intl/Date | 日本目标是 Tokyo 与 UTC+9；仅 UTC+9 不能区分日本与其他地区 |
| 时间同步 | 当前时间、同步设置，确有差异再对照可信时间源 | 时间错误可影响 TLS/会话，时间服务器国家不是身份凭据 |
| 地区格式、UI、语言列表 | Windows Culture/HomeLocation/UI/LanguageList；macOS AppleLocale；Linux locale | 日期数字格式与界面语言分别记录 |
| 输入法、键盘 | 当前语言列表，需要时人工核对 | 保留工作需要的输入法，不据此推断国籍 |
| 进程继承 | LANG、LC_*、TZ、启动文件及启动时间 | 已有进程可能保留旧值，只重启受影响应用 |
| WSL、Docker、SSH、云会话 | 在实际运行应用的同一上下文采集 | 宿主机设置不能覆盖远端事实，不自动连接未授权机器 |

## 浏览器

| 检测面 | 证据 | 判读与动作 |
|---|---|---|
| 语言与请求头 | navigator.language(s) 与实际 Accept-Language | 两者分别取证，扩展、策略和隐私模式可能改变值 |
| Intl | DateTimeFormat/NumberFormat/Collator 与格式示例 | 对照目标地区，中文内容本身不是环境泄漏 |
| 窗口、iframe、Worker | 各上下文的语言和 Intl | 本地页不覆盖站点专属扩展；未测上下文记未验证 |
| UA、UA-CH | UA、brands/platform/mobile、高熵 model/platformVersion | 型号、OS 与 UA 应自洽，隐藏或不支持 API 不是通过 |
| 字体 | Canvas 相对度量与系统字体分别记录 | 检测受浏览器保护影响；中文字体普遍存在于多语种系统，不卸载系统字体 |
| Canvas、WebGL、WebGPU | API 支持、renderer/vendor、真实平台 | 可暴露运行环境，不能据 GPU 判地区，无需收集像素哈希 |
| 音频、语音 | API 支持及 speechSynthesis 语音语言 | 反映组件安装，不生成音频指纹、不打开麦克风 |
| 屏幕、DPR、触控、CPU、内存 | 浏览器可见属性 | 只检查明显自相矛盾，不存在“日本人标准硬件” |
| 精确地理定位 | 目标站点权限与系统定位设置 | 默认不请求坐标；改时区不会改变 GPS |
| Cookie、站点状态、Service Worker | 站点设置与用户核对的历史 | 可能关联已有会话，不导出登录数据、不为检测清空历史 |
| 扩展、企业策略、代理扩展 | 启用的相关扩展与浏览器策略页 | 扩展可能仅覆盖部分域名或上下文，重测相关部分 |
| 自动化 | webdriver 与浏览器启动方式 | 标明测试上下文，不把自动化伪装当成用户真实配置 |

## 原生客户端与外部信息

- Claude Code：确认二进制路径、版本、实际环境变量、配置优先级与目标 endpoint。网页字体/WebRTC 不能自动外推到 CLI。
- IDE/Desktop：主进程和内部终端可能继承不同环境。重启窗口与重启后台进程的效果应分别验证。
- TLS/HTTP2/HTTP3：服务端可见协议特征，本地改 UA 不会自动改变它们。无受控服务端观测时记未验证，不安装中间人证书做本次检查。
- 任务上下文中的路径、用户名、日志、Git 时区和提供给 agent 的文本可能包含语言或地区线索。仅在实际任务会发送的内容中核对，不批量扫描私人文档、不篡改材料或 Git 历史。
- 账号历史、注册资料、账单、手机号、服务端设备与会话历史不属于本机采集器可验证范围。由用户核对真实资料，网络切换不会重写历史。

## 限制

这是检测面地图，执行时按实际场景取证，不机械调用全部 API。“中国相似度低”与“日本地区设置一致”是不同命题，任何配置组合都不能证明人的国籍。
